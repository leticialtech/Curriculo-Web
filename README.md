# Currículo Web - Letícia Leme Medeiros

Página de currículo pessoal desenvolvida em HTML e CSS puro, como trabalho da matéria de Tecnologias Web (PUC-Campinas).

🔗 **Acesse o site:** https://leticialtech.github.io/Curriculo-Web/

## Sobre o projeto

O site é dividido em duas páginas, navegadas na mesma guia:

- **index.html** — página de entrada, com um convite (imagem de carta) para conhecer o currículo.
- **curriculo.html** — o currículo em si, com navegação interna por âncoras entre as seções: Sobre mim, Experiências, Formação e Contato.

## Tecnologias utilizadas

- HTML5
- CSS3 (arquivo externo `estilo.css`, sem frameworks)
